Start using idtracker.ai
========================

1.  Check the :doc:`how_to_install` section to easily install idtracker.ai in your computer.

2.  Start using idtracker.ai following the :ref:`usage` page with one of your videos or start with the short example video you get from the :ref:`test the installation` section. You'll learn to:

    - Use the :ref:`segmentation app` to set the basic input parameters.
    - Learn how to run from the terminal without graphical interfaces.
    - Expand idtracker.ai's capabilities by using :ref:`advanced parameters`.

3.  Use idtracker.ai extra tools:

    - Validator
    - Video generator
    - convert to csv
    - idmatcher.ai

4.  Get your processed trajectory file and start your own research or start by using our basic trajectory analysis Python scripts.


.. tip::
    If you are unsure whether idtracker.ai will work on your videos, check our :ref:`guidelines for good videos` and the :ref:`example videos` we have to see if your videos would fit.
